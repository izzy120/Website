# InkyShaman Business Platform

## Overview

InkyShaman is a full-stack business management platform for a mobile IT service company.

## Technology Stack

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Python
- FastAPI

### Database
- SQLite (development)
- PostgreSQL (future production)

### Payments
- Stripe

### Notifications
- Email
- SMS (Twilio)

## Current Features

- Landing Page
- Services Section
- Booking Form
- FastAPI Backend
- Appointment API

## Planned Features

- Availability Calendar
- Stripe Payments
- Customer Dashboard
- Admin Dashboard
- Inventory Management
- AI Assistant (X.A.N.A.)
